## 过程记录

### 需求梳理

本阶段的目标是实现一个 TypeScript 命令行 SVG 编辑器。

- 内置图形：rect、circle、ellipse、line、text、g。
- 功能范围：文档读写、图形编辑、容器与层级管理、结构显示、撤销与重做。
- 实现要求：面向对象、封装、多态、一类一文件，使用 Command 模式。
- 交付要求：远程 Git 仓库、分步提交历史、架构与过程文档、最终 final 标签。
- box 与插件系统属于后续阶段。

后续在这里记录实际的设计讨论、发现的问题、修改及验证过程。
